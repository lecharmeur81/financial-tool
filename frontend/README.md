# Frontend — Capital Flow Intelligence

Next.js 16 (App Router) · React 19 · TypeScript (strict). Presentation only: all data comes from the
FastAPI backend (`API_INTERNAL_URL`, read on the server at request time). Project rules: `../CLAUDE.md`.

This Next.js version differs from older ones; its own docs ship in `node_modules/next/dist/docs/`
(see `AGENTS.md`, generated by Next.js).

| Task             | Command (from `frontend/`, needs pnpm 10.28)                  |
| ---------------- | ------------------------------------------------------------- |
| Install          | `pnpm install`                                                |
| Dev server       | `API_INTERNAL_URL=http://localhost:8000 pnpm dev`             |
| Lint             | `pnpm lint`                                                   |
| Format / check   | `pnpm format` / `pnpm format:check`                           |
| Type check       | `pnpm typecheck` (generates route types, then `tsc --noEmit`) |
| Tests            | `pnpm test`                                                   |
| Production build | `pnpm build`                                                  |
